# Marginal return

Asks a sharper question than the platform's average return: did the last step up in spend pay for itself? It compares the weeks a channel spent more with the weeks it spent less, on Shopify's revenue and orders and the store's own margin, and gives scale, hold or cut.

- Reads: Shopify orders, the store's costs, and Meta or Google Ads spend.
- Writes: nothing. Any budget step is a plan you make yourself.
- Costs: nothing from a provider.
- You approve: nothing, because nothing changes.
