# Holdout test planner

Writes a test plan that shows what a flow or an ad channel truly adds, instead of what it claims. Two designs fit a small store: holding the welcome emails back from a random tenth of new subscribers, or holding one channel's ads back in a set of regions. The plan is sized from your own orders and sets the decision rule before the test starts.

- Reads: Shopify orders, and Klaviyo when connected.
- Writes: nothing and starts nothing. You set the test up yourself.
- Costs: nothing from a provider.
- You approve: nothing, because nothing changes.
